# Money Manager Android

这是一个原生 Android 资产更新助手。它不登录银行或券商账户，只记录每项资产的更新时间，并在你点击时打开对应的银行、券商或钱包 App。

## 当前功能

- 新增、编辑、删除资产
- 记录资产名称、类型、机构、金额、币种、更新周期、最后更新时间
- 使用底部总览 / 趋势 / 资产一体式导航，选中项整块高亮，设置放在顶部图标入口
- 每个页面顶部提供导航列表，长页面可以直接跳到目标区块
- 统一按钮、卡片和页签视觉，并提供启动图标
- 设置里显示当前版本，可检查 GitHub Release 最新版本、打开固定 APK 下载地址或复制链接
- 总览展示净资产、资产总额、负债、更新状态
- 总览里的净资产、资产总额、负债、更新状态和汇率说明可点击进入对应调整入口
- 可设置年度净资产目标，展示进度、差额和所需月均增量
- 一键复制资产摘要，方便贴到备忘录或发给自己复盘
- 行动中心合并待办、数据质量和优先核对资产，避免同类提醒分散在多个入口
- 总览页按资产类型展示比例图和比例明细
- 可设置资产类型目标比例，并提示低配 / 超配方向
- 按机构汇总资产分布，显示金额、占比和资产数量
- 记录本地每日总资产快照，展示近一年变化趋势
- 趋势页会从新版快照开始记录并展示资产类型分布变化
- 支持按单项资产查看金额趋势，便于看某张卡、某个券商账户或某项负债的变化
- 趋势复盘会展示近 30 天、90 天和一年的阶段变化、高点和低点
- 支持补录近一年历史快照，便于补足过去的总资产变化
- 趋势图下方展示最近快照，可删除误记的历史快照
- 资产管理区域可折叠和展开
- 资产管理会按类型分组展示小计，每个类型组也可折叠和展开
- 资产卡片显示类型图标、App 绑定状态和短操作按钮
- 资产管理支持搜索、筛选全部 / 待更新 / 未绑定 / 待完善 / 负债，并优先显示最需要处理的资产
- 行动中心会按周期列出最该核对的资产，并提供“打开 App / 已更新”快捷操作
- “已更新”会弹出带资产摘要的最新金额录入框，可顺手改余额并记录快照
- 最近更新会记录每次核对前后的金额变化，便于回看维护轨迹
- 更新金额时可标记变化原因，例如入金、出金、市场涨跌、转账或费用
- 行动中心会提示目标偏离、多币种、负债率和数据质量风险
- 本地 JSON 备份和恢复，便于换机或手动留档
- 启动时自动获取常用币种最新汇率，也可在设置里手动刷新或修改
- 隐私模式可一键隐藏总资产、资产金额和趋势金额变化
- 根据更新周期标记“新鲜 / 待更新 / 已过期”
- 首次绑定时只能从带图标和搜索的已安装 App 列表中选择，不需要输入技术信息
- App 选择器支持按名称或包名搜索，并显示当前匹配数量，但界面只显示 App 名称
- 未绑定资产点击“打开 App”会直接选择并绑定已安装 App
- 已绑定资产点击“打开 App”拉起对应应用
- 从外部 App 返回后，直接提示录入最新金额或仅刷新更新时间
- 数据保存在本机 `SharedPreferences`

## 运行方式

1. 用 Android Studio 打开 `android/` 目录。
2. 等待 Gradle 同步。
3. 连接 Android 手机或启动模拟器。
4. 运行 `app` 模块。

命令行构建需要本机安装 Java、Android SDK 和 Gradle：

```bash
cd android
gradle :app:assembleDebug
```

当前 Codex 环境没有 Java / Gradle / Android SDK，所以这里没有直接编译 APK。

## 源码结构

- `model/`：资产、快照、更新事件、组合设置等数据模型
- `data/`：本地存储、备份导入导出、快照维护
- `domain/`：资产汇总、币种换算、版本检查、过期判断等计算逻辑
- `ui/`：底部导航、页内导航、资产分布图、趋势图和 App 选择器等界面模块

## 如何绑定 App

编辑资产时只需要点击“选择 App”，从已安装 App 列表里选择一次。界面只显示 App 名称，内部会保存打开 App 所需的信息。

未绑定资产也可以直接点资产卡片或行动中心里的“打开 App”。App 会先让你从已安装 App 中选择，绑定成功后立即尝试打开。

## 趋势如何产生

App 会在这些时刻记录当天总资产快照：

- 新增、编辑或删除资产
- 点击“已更新”并保存金额，或选择“仅更新时间”
- 点击“记录今日快照”
- 点击“补录快照”手动录入近一年内某天的净资产、资产总额和负债

同一天多次记录会覆盖当天快照，只保留最新值。趋势图保留最近约一年数据。
趋势复盘会按近 30 天、90 天和一年分别计算净资产变化，并显示区间高点和低点；隐私模式下只显示快照数量和区间，不显示金额。新版快照还会保存资产类型分布，记录两次之后趋势页会展示每类资产金额和占比的变化。趋势页也可以选择单项资产，查看该资产历次更新金额形成的趋势。
趋势图下方会显示最近 6 条快照。发现某天误记时，可以直接删除该快照，图表和趋势说明会立即刷新。
补录快照会使用当前基准币种；如果你切换了基准币种，趋势图会按当前基准过滤快照，避免不同口径混在一起。

当前总资产计算是轻量版本：负债类型会从净资产中扣除；多币种资产会按最新获取或本地维护的汇率换算。

## 年度目标

总览页里的“年度目标”可以设置目标净资产和截止日期。App 会按当前基准币种展示：

- 当前目标进度
- 距离目标还差多少
- 剩余天数
- 按剩余时间估算的每月净资产增量

如果目标已经达成，行动中心会提示已达到；如果目标日期临近且还有差额，行动中心会把它列出来。隐私模式下会隐藏目标金额、进度和差额。

## 目标比例

总览页的“目标比例”里可以给每类资产设置长期目标，比如现金、券商、基金、房产、负债分别占多少。保存时目标合计需要接近 100%。

设置后，App 会按当前总资产估算每类资产和目标的偏离：

- 当前占比、目标占比和偏离百分点
- 低配 / 超配状态
- 在非隐私模式下，估算需要增加或减少多少金额才能接近目标

这些提醒也会进入“行动中心”和“复制摘要”，方便复盘时一起看。

## 行动中心

总览页里的“行动中心”合并了原来的待办、数据健康和更新计划。它会先给出目标或风险摘要，再按每项资产的更新周期排序：

- 从未更新和已逾期的资产排在前面
- 3 天内到期的资产会被单独计数
- 每项资产都可以直接打开对应 App，或手动录入最新金额
- 缺金额、缺机构、未绑定 App、缺汇率等维护问题会集中显示在同一张卡片里

保存更新后，App 会同步记录当日总资产快照，趋势图也会跟着更新。如果你只想刷新更新时间，也可以在弹窗里选择“仅更新时间”。

## 最近更新

每次保存更新时，App 会记录：

- 资产名称
- 更新时间
- 更新前金额和更新后金额
- 本次变化金额
- 变化原因
- 当时填写的备注

资产页里的“最近更新”卡片会汇总近 30 天的更新次数，并按当前基准币种折算净变化和变化原因。这能替代一部分逐笔流水记录：你不必把每次股票买卖都录成交易，只要核对账户余额时保存最新金额，并粗略标记是入金、出金、市场涨跌、转账或费用，就能回看短期和单次净变化。误记的更新记录可以删除；删除记录不会回滚资产金额或趋势快照。最近更新记录会随备份导出和恢复。

## 备份与恢复

顶部设置图标里有“数据备份”入口：

- `导出备份`：保存资产列表、绑定 App 信息、更新时间、趋势快照、更新记录、变化原因、本地汇率、年度目标和目标比例到 JSON 文件
- `导入备份`：读取之前导出的 JSON 文件，并覆盖当前本机数据

备份文件不包含银行或券商密码，但会包含你的资产名称、金额、机构、绑定 App 信息、本地汇率、年度目标和目标比例。建议只保存在你信任的位置。

## 隐私模式

总资产概览里有“隐藏金额 / 显示金额”按钮。隐藏后：

- 总资产、资产总额、负债数字会被遮住
- 单项资产金额会被遮住
- 趋势的金额变化会被遮住

比例、更新状态、行动中心仍然可见，方便在公共场合快速操作。复制资产摘要时也会沿用当前隐私模式。

## 多币种

总资产默认以 `CNY` 为基准，内置了常见币种的初始汇率。App 启动时会尝试从 Frankfurter 获取 `CNY / USD / HKD / EUR / JPY` 的最新公开汇率；你也可以在顶部设置图标的“基准币种与汇率”中手动刷新或修改：

- 基准币种
- `CNY / USD / HKD / EUR / JPY` 到基准币种的换算率

获取失败时会继续使用本机已保存的汇率。

## 权限说明

`AndroidManifest.xml` 里使用了：

```xml
<uses-permission android:name="android.permission.INTERNET" />
<queries>
    <intent>
        <action android:name="android.intent.action.MAIN" />
        <category android:name="android.intent.category.LAUNCHER" />
    </intent>
</queries>
```

`<queries>` 用于在 Android 11+ 上读取可启动 App 列表，并在你选择后拉起对应外部 App；没有再申请敏感的 `QUERY_ALL_PACKAGES`。`INTERNET` 用于获取公开汇率，不会登录银行或券商账户。
