# Money Manager Android

这是一个原生 Android 资产更新助手。它不登录银行或券商账户，只记录每项资产的更新时间，并在你点击时打开对应的银行、券商或钱包 App。

## 当前功能

- 新增、编辑、删除资产
- 记录资产名称、类型、机构、金额、币种、更新周期、最后更新时间
- 总资产页展示净资产、资产总额、负债、更新状态
- 按资产类型展示比例图和比例明细
- 按机构汇总资产分布，显示金额、占比和资产数量
- 记录本地每日总资产快照，展示近一年变化趋势
- 趋势图下方展示最近快照，可删除误记的历史快照
- 资产管理区域可折叠和展开
- 资产管理支持搜索、筛选全部 / 待更新 / 未绑定 / 负债，并优先显示最需要处理的资产
- 更新计划会按周期列出最该核对的资产，并提供“打开 App / 已更新”快捷操作
- “已更新”会弹出最新金额录入框，可顺手改余额并记录快照
- 最近更新会记录每次核对前后的金额变化，便于回看维护轨迹
- 待办提醒会提示过期资产、未绑定 App、多币种和负债率风险
- 本地 JSON 备份和恢复，便于换机或手动留档
- 基准币种和手动汇率设置，多币种资产会换算后进入总资产
- 隐私模式可一键隐藏总资产、资产金额和趋势金额变化
- 根据更新周期标记“新鲜 / 待更新 / 已过期”
- 首次绑定时可以从已安装 App 列表中选择，不需要手动查包名
- 点击“打开 App”拉起对应应用
- 从外部 App 返回后，直接提示录入最新金额或仅刷新更新时间
- 数据保存在本机 `SharedPreferences`

## 运行方式

1. 用 Android Studio 打开 `android/` 目录。
2. 等待 Gradle 同步。
3. 连接 Android 手机或启动模拟器。
4. 运行 `app` 模块。

命令行构建需要本机安装 Java、Android SDK 和 Gradle：

```bash
cd android
gradle :app:assembleDebug
```

当前 Codex 环境没有 Java / Gradle / Android SDK，所以这里没有直接编译 APK。

## 不写代码，直接下载 APK

这个仓库已经配置了 GitHub Actions 自动构建：

1. 打开 GitHub 仓库页面。
2. 进入 `Actions`。
3. 点击 `Build Android APK`。
4. 选择最新一次成功运行。
5. 在页面底部 `Artifacts` 下载 `money-manager-debug-apk`。
6. 解压后得到 `money-manager-debug.apk`，发送到 Android 手机安装。

如果想手动重新构建：

1. 进入 `Actions -> Build Android APK`。
2. 点击 `Run workflow`。
3. 等待运行成功后下载 artifact。

这个 APK 是 debug 版，适合个人自用和测试。手机安装时可能需要允许“安装未知来源应用”。

## 如何绑定 App

编辑资产时填写：

- `App 包名`：可以点击“选择已安装 App”自动填入，也可以手动输入
- `启动链接`：可选，如果某个 App 提供 deep link，可以填入类似 `xxx://home`

如果只填包名，应用会尝试打开该 App 的主入口。如果没有安装，会尝试跳到应用商店页面。

## 趋势如何产生

App 会在这些时刻记录当天总资产快照：

- 新增、编辑或删除资产
- 点击“已更新”并保存金额，或选择“仅更新时间”
- 点击“记录今日快照”

同一天多次记录会覆盖当天快照，只保留最新值。趋势图保留最近约一年数据。
趋势图下方会显示最近 6 条快照。发现某天误记时，可以直接删除该快照，图表和趋势说明会立即刷新。

当前总资产计算是轻量版本：负债类型会从净资产中扣除；多币种资产会按你在“基准币种与汇率”里维护的本地汇率换算。

## 更新计划

总资产页里的“更新计划”会按每项资产的更新周期排序：

- 从未更新和已逾期的资产排在前面
- 3 天内到期的资产会被单独计数
- 每项资产都可以直接打开对应 App，或手动录入最新金额

保存更新后，App 会同步记录当日总资产快照，趋势图也会跟着更新。如果你只想刷新更新时间，也可以在弹窗里选择“仅更新时间”。

## 最近更新

每次保存更新时，App 会记录：

- 资产名称
- 更新时间
- 更新前金额和更新后金额
- 本次变化金额
- 当时填写的备注

最近更新卡片还会汇总近 30 天的更新次数，并按当前基准币种折算净变化。这能替代一部分逐笔流水记录：你不必把每次股票买卖都录成交易，只要核对账户余额时保存最新金额，就能回看短期和单次净变化。最近更新记录会随备份导出和恢复。

## 备份与恢复

总资产页里有“数据备份”区域：

- `导出备份`：保存资产列表、绑定 App 包名、更新时间、趋势快照、更新记录和本地汇率到 JSON 文件
- `导入备份`：读取之前导出的 JSON 文件，并覆盖当前本机数据

备份文件不包含银行或券商密码，但会包含你的资产名称、金额、机构、App 包名和本地汇率。建议只保存在你信任的位置。

## 隐私模式

总资产概览里有“隐藏金额 / 显示金额”按钮。隐藏后：

- 总资产、资产总额、负债数字会被遮住
- 单项资产金额会被遮住
- 趋势的金额变化会被遮住

比例、更新状态、待办提醒仍然可见，方便在公共场合快速操作。

## 多币种

总资产默认以 `CNY` 为基准，内置了常见币种的初始汇率。你可以在总资产页的“基准币种与汇率”中修改：

- 基准币种
- `CNY / USD / HKD / EUR / JPY` 到基准币种的换算率

汇率只保存在本机，不会自动联网更新。

## 权限说明

`AndroidManifest.xml` 里使用了：

```xml
<uses-permission android:name="android.permission.QUERY_ALL_PACKAGES" />
```

这是为了个人自用时能根据你手动输入的任意包名拉起外部 App。这个权限对 Play Store 上架比较敏感。如果未来要公开发布，建议改成固定 allowlist 的 `<queries>` 配置，或只支持用户填写 deep link。
